# ʿIlm al-Nujûm

## Définition

L’*ʿilm al-nujûm* (science des astres) est la discipline astrologique traditionnelle islamique, fondée sur l’étude des sept planètes visibles, des douze signes zodiacaux et des douze maisons pour interpréter les influences célestes sur les destinées humaines et les événements terrestres.

## Développement

### Fondements

L’*ʿilm al-nujûm* repose sur la correspondance entre le monde supérieur et le monde inférieur — principe partagé avec l’*[[ilm-al-huruf]]* d’[[ahmad-al-buni]] : les sphères planétaires influencent en cascade les éléments terrestres (Trône → Siège → Saturne → … → Lune → 4 éléments).

La discipline se distingue de l’astrologie moderne par plusieurs principes (source : [[ilm-al-nujum-astrologie-traditionnelle]]) :

- Seules les **sept planètes visibles à l’œil nu** sont considérées (Soleil, Lune, Mercure, Vénus, Mars, Jupiter, Saturne)
- Les planètes dites « modernes » (Uranus, Neptune, Pluton) sont exclues
- Le zodiaque utilisé est **tropical** (ancré sur le Point Vernal / équinoxe de printemps)
- L’interprétation intègre dignités, maisons, aspects et nœuds lunaires dans une **synthèse globale**

### Les dignités planétaires

Chaque planète est plus ou moins forte selon sa position dans le zodiaque. Par ordre de force décroissante : Trône/Domicile → Exaltation → Exil → Chute. Ces dignités conditionnent l’interprétation de toute configuration astrologique.

### Les 12 maisons

Les maisons astrologiques (*al-buyūt*) représentent les domaines de la vie terrestre. Elles sont de trois types :

- **Cardinales** (I, IV, VII, X) : maisons d’action directe, les plus puissantes
- **Succédantes** (II, V, VIII, XI) : maisons de consolidation
- **Mutables** (III, VI, IX, XII) : maisons de transition et d’adaptation

### Les aspects

Les aspects (*al-naẓar*) mesurent les relations angulaires entre planètes. Les bénéfiques (conjonction, sextil, trigone) favorisent la réalisation ; les maléfiques (opposition, quadrature) créent tension et conflit, pouvant être tempérés par d’autres configurations.

### Dimension spirituelle

Le document source cite [[ibn-arabi]] (le Shaykh al-Akbar) : pour chaque être, l’existence est un voyage, et les aspects astrologiques permettent d’en percevoir les modalités. L’*ʿilm al-nujûm* est ainsi intégré dans une vision spirituelle où les astres sont des signes (*ʿalāmāt*) du Créateur — lien direct avec la cosmologie akbarienne de la [[wahdat-al-wujud]].

### Lien avec l’*ʿilm al-ḥurūf*

Les deux disciplines partagent le même système de correspondances planétaires : dans l’*[[ilm-al-huruf]]*, chaque planète est associée à une lettre arabe et un nombre *abjad* ; dans l’*ʿilm al-nujûm*, ces mêmes planètes gouvernent signes, maisons et cycles temporels. Elles constituent deux lectures complémentaires du même cosmos symbolique.
