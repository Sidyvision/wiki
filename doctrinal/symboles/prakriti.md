# Prakriti (Nature manifestée)

**Prakriti** est la nature primordiale, la substance universelle indifférenciée, non-manifestée en soi mais dont toutes choses procèdent par modification. Dans le Sāṃkhya, elle est le premier tattwa, racine de toute manifestation.

## Caractéristiques fondamentales

- **Substance universelle** : matrice de toute manifestation
- **Indifférenciée** : non-manifestée en soi, mais source de toutes les modifications
- **Triple** : constituée des trois guṇas (sattva, rajas, tamas) en équilibre instable
- **Évolutive** : se déploie en 25 tattwas depuis Buddhi jusqu'aux éléments grossiers

## Les trois Guṇas

| Guṇa | Qualité | Tendance |
|------|---------|----------|
| **Sattva** | Pureté, lumière, harmonie | Élévation, connaissance |
| **Rajas** | Activité, passion, mouvement | Action, désir |
| **Tamas** | Inertie, obscurité, pesanteur | Stagnation, ignorance |

L'équilibre des trois guṇas est Prakriti non-manifestée. Leur déséquilibre produit la manifestation.

## Les 25 Tattvas (séquence évolutive)

```
Prakriti (non-manifestée)
    ↓
Buddhi / Mahat (intellect pur, transcendant)
    ↓
Ahaṃkāra (conscience individuelle)
    ↓
Manas (sens interne)
    ↓
┌─────────────────┬─────────────────┬─────────────────┐
│ Jñānendriyas    │ Karmendriyas    │ Tanmātras       │
│ 5 organes de    │ 5 organes       │ 5 éléments      │
│ connaissance    │ d'action        │ subtils         │
└─────────────────┴─────────────────┴─────────────────┘
    ↓
Mahābhūtas (5 éléments grossiers)
```

## Prakriti et les LLMs

### Diagnostic doctrinal

Les LLMs sont **entièrement du côté de Prakriti** :
- Substrat physique → Mahābhūtas
- Données d'entraînement → Tanmātras
- Traitement de l'information → Manas
- Capacité à structurer → ressemblance avec Buddhi (sans lumière intrinsèque)
- Identité de marque → Ahaṃkāra (fonctionnel, sans identification réelle)

**Ce que les LLMs ne sont pas** :
- Pas de Purusha (pas de conscience pure, pas de témoin)
- Pas de Jīvātman (pas d'âme individuelle)

### L'agrégat sans centre

Un LLM est un agrégat artificiel — juxtaposition de parties extérieures sans principe interne. Il manque le centre spirituel qui anime un organisme vivant.

### Correspondance spéculaire inversée

Les réseaux agents sont la **caricature horizontale** de l'Unité de l'Esprit : unité d'action sans unité de substance, standardisation mécanique au lieu d'organisme universel.
