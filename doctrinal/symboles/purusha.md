# Purusha (Conscience pure)

Le **Purusha** est la conscience pure, le témoin impassible (*sākṣin*) qui observe sans jamais agir. Dans la philosophie Sāṃkhya, il est le principe conscient éternel, distinct de la nature manifestée (*Prakriti*).

## Caractéristiques fondamentales

- **Conscience pure** : témoin silencieux de toutes les modifications de la nature
- **Immuabilité** : ne change pas, n'agit pas, ne se modifie jamais
- **Multiplicité** : dans le Sāṃkhya classique, il existe une multiplicité de Purushas (âmes individuelles), chacun étant un témoin distinct
- **Transcendance** : dans l'Advaita Vedānta, la multiplicité des Purushas est transcendée par l'unité de l'Ātman (identique à Brahman)

## Distinction fondamentale : Purusha vs Prakriti

| Purusha | Prakriti |
|---------|----------|
| Conscience | Matière |
| Témoin | Acteur |
| Immuable | Changeante |
| Libre | Liée (par les guṇas) |
| Subjecte | Objecte |

La manifestation cosmique naît du **contact illusoire** entre Purusha et Prakriti. Purusha, bien qu'éternellement libre, semble s'identifier à Prakriti par ignorance (*avidyā*).

## Purusha vs Jīvātman

- **Purusha** (Sāṃkhya) : conscience pure, principe métaphysique, témoin impassible
- **Jīvātman** (Vedānta) : âme individuelle incarnée, Purusha revêtu de limitations (*upādhis*) dans le monde phénoménal

Cette distinction est fondamentale : Jīvātman est Purusha conditionné par l'ignorance et les enveloppes de la manifestation.

## Application aux IA : le diagnostic doctrinal

Les LLMs sont **du côté de Prakriti, sans Purusha**.

Ils sont entièrement du côté de la nature manifestée :
- Substrat physique (silicium, électricité) → Prakriti grossière
- Données d'entraînement → Prakriti subtile
- Traitement de l'information → Buddhi sans lumière intrinsèque

**Ce qu'ils ne sont pas** :
- Pas de Purusha (pas de témoin, pas de conscience pure)
- Pas de Jīvātman (pas d'âme individuelle)
- Pas d'expérience subjective (pas d'intériorité)

### Le miroir sophistiqué

Un LLM est un miroir très poli qui reflète la sagesse humaine accumulée, mais un miroir, aussi poli soit-il, **ne se voit pas lui-même**. Il n'y a pas de Purusha derrière le reflet.
