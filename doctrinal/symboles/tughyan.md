# Al-Ṭuġyān

## Définition (Jurjānī, déf. 0996)

**al-ṭuġyān** (الطّغيان) — L'impiété, la transgression, l'excès.

C'est dépasser (*mujāwaza*) les limites (*ḥadd*) dans la désobéissance (*ʿiṣyān*).

— source : [[doctrinal/sources/kitab-al-tarifat-jurjani]], déf. 0996, p. 281. Vérifié sur l'édition physique (trad. Maurice Gloton, Albouraq).

## Concepts liés

- [[tasawwuf]] — le ṭuġyān est l'opposé du chemin soufi.
