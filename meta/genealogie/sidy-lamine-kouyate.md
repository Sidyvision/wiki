# Sidy-Lamine Kouyaté

## Description

Nom complet de l'utilisateur du présent dépôt, connu partout ailleurs sous
son prénom d'usage **Sidy** (voir [[meta/personnel/sidy]] pour le profil
spirituel et intellectuel, déjà documenté séparément — cette fiche ne le
reproduit pas, Cmd 4 : une page = un sujet). Fiche strictement généalogique,
créée le 2026-08-10 pour servir de nœud de convergence entre les deux
lignées documentées dans `meta/genealogie/` et pour combler des liens à
référent vide relevés dans plusieurs fiches `doctrinal/discernement/

`doctrinal/annales.md`).
